## M6 — FinnhubProvider

**File:** `onefinance/providers/finnhub.py`
**Pattern:** mirrors `fmp.py` — subclass `BaseProvider`, implement a `_get()` HTTP helper, normalize raw responses to Pydantic models.

### Endpoints supported

| Endpoint | Finnhub API path | Notes |
|---|---|---|
| `get_price_history` | `/stock/candle` | Returns OHLCV JSON; `resolution=D` for daily |
| `get_quote` | `/quote` | Current price, bid, ask, volume |
| `get_financials` | `/financials-reported` | Income/balance/cashflow via `statement` param |
| `get_info` | `/stock/profile2` | Company profile |
| `get_ratios` | `/stock/metric` | Basic financials (P/E, P/B, margins, etc.) |
| `get_earnings` | `/stock/earnings` | EPS actuals + estimates |
| `get_insider_trades` | `/stock/insider-transactions` | Form 4 filings |

### Rate-limit detection

- HTTP 429 → `RateLimitError`; read `Retry-After` header for `retry_after_seconds`
- Free tier: 60 calls/minute. Cooldown: `Retry-After` value if present, else 60 s.

### Constructor

```python
FinnhubProvider(api_key: str | None = None, timeout: int = 10, base_url: str = ...)
# api_key falls back to FINNHUB_API_KEY env var
# raises ConfigError if no key found
```

### Tests

28 unit tests with mocked `httpx` (matching fmp test count), covering:
- Each endpoint's happy path
- Empty-response handling (returns `[]`)
- Rate-limit detection (HTTP 429 + `Retry-After`)
- `NotSupportedError` default for unimplemented endpoints (from base)

## M7 — TwelveDataProvider

**File:** `onefinance/providers/twelve_data.py`
**Scope:** `get_price_history` and `get_quote` only (per design doc §3 capability matrix).

### Endpoints supported

| Endpoint | Twelve Data API path | Notes |
|---|---|---|
| `get_price_history` | `/time_series` | `interval=1day`, `outputsize` from date range |
| `get_quote` | `/quote` | Includes bid/ask |

All other endpoints raise `NotSupportedError` (default base behavior).

### Rate-limit detection

- HTTP 429 → `RateLimitError`
- Body JSON `{"code": 429, ...}` → `RateLimitError`
- Free tier: 800/day, 8/min. Cooldown: 60 s.

### Constructor

```python
TwelveDataProvider(api_key: str | None = None, timeout: int = 10, base_url: str = ...)
# api_key falls back to TWELVE_DATA_API_KEY env var
# raises ConfigError if no key found
```

### Tests

~15 unit tests with mocked `httpx` covering both endpoints + rate-limit detection.

## M9 — CLI: Data Commands

**Files:**
- `onefinance/cli/app.py` — Typer app, all command definitions
- `onefinance/cli/format.py` — JSON/table/CSV rendering
- `onefinance/cli/__main__.py` — `python -m onefinance.cli` entry point

### Command surface

```
ofclient price SYMBOL [--start DATE] [--end DATE] [--range 1y|6m|3m|1m]
ofclient quote SYMBOL
ofclient financials SYMBOL --statement income|balance|cashflow --period annual|quarterly
ofclient info SYMBOL
ofclient insiders SYMBOL [--since DATE]
ofclient ratios SYMBOL --period annual|quarterly [--fresh]
ofclient earnings SYMBOL [--fresh]
```

Universal flags on all data commands: `--no-cache`, `--provider NAME`, `--ttl SECONDS`, `--format json|table|csv`, `--config PATH`

### Output envelope (JSON default)

```json
{
  "schema_version": "1.0",
  "status": "success",
  "command": "<name>",
  "data": [...],
  "metadata": {"source": "fmp", "cache_hit": false, "fetched_at": "...", "rows": N}
}
```

Error envelope:
```json
{"schema_version": "1.0", "status": "error", "command": "<name>", "error": {<FinanceError.to_dict()>}}
```

### Exit codes

| Code | Meaning |
|---|---|
| 0 | Success |
| 1 | User error (bad args, unknown symbol) |
| 2 | Transient (rate limit, network) |
| 3 | Permanent (endpoint not supported) |
| 4 | Configuration error (missing API key) |

### format.py responsibilities

- `print_json(envelope)` — pretty-print JSON to stdout
- `print_table(data, command)` — Rich table, columns vary by command
- `print_csv(data)` — CSV to stdout
- `make_envelope(command, data, metadata)` → dict
- `make_error_envelope(command, error)` → dict

### Help text convention

Each command docstring follows the four-section pattern from DESIGN.md §16:
DESCRIPTION / WHEN TO USE / WHEN NOT TO USE / EXAMPLES

### `__main__.py`

```python
from onefinance.cli.app import app
if __name__ == "__main__":
    app()
```

### Tests

- Unit tests for `format.py` (envelope construction, CSV/table output)
- CLI integration tests using Typer's `CliRunner` for each command's happy path and error paths

## M10 — CLI: Introspection

**Added to `app.py`:**

```
ofclient capabilities          # JSON manifest of all commands + schemas
ofclient version               # version + schema_version
ofclient config init           # write ~/.onefinance/config.yaml template
ofclient config show           # print current config
ofclient cache stats           # entries, size_mb, hit rate
ofclient providers status      # per-provider cooldown/health state
```

`--dry-run` added to all data-fetching commands — prints plan JSON without fetching.

Dry-run plan JSON:
```json
{
  "status": "dry_run",
  "command": "<name>",
  "plan": {
    "would_fetch": false,
    "cache_hit_predicted": true,
    "cache_key": "price:a3f9c2e8",
    "ttl_remaining_s": 3600
  }
}
```

### capabilities manifest

Machine-readable JSON listing every command with its arguments, types, allowed values, freshness type, and examples. Backed by a static dict in `app.py` (one entry per command) — not introspected from Typer at runtime. Each entry includes: `name`, `description`, `freshness_type` (A/B/C), `arguments` (name/type/required/allowed values/default), and `examples`.

### Environment overrides (all read in `app.py`)

| Variable | Equivalent flag |
|---|---|
| `OFCLIENT_OUTPUT` | `--format` |
| `OFCLIENT_NO_CACHE` | `--no-cache` |
| `OFCLIENT_DRY_RUN` | `--dry-run` |
| `OFCLIENT_CONFIG` | `--config` |
